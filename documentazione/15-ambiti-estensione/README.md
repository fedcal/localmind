# 15 — Ambiti di estensione di LocalMind

Questa sezione documenta **ogni ambito** in cui LocalMind può estendersi grazie al motore di Knowledge Graph universale. Ogni ambito ha un file dedicato (IT + EN) con struttura estesa: cosa risolviamo, personas, requisiti in input, flusso dell'attività, modello a grafo (nodi/archi/pesi), fonti dati & connettori, funzionalità da creare/sviluppare/mantenere (MVP → evoluzione), casi d'uso AI/GraphRAG, KPI, rischi, manutenzione, integrazione con i moduli esistenti.
