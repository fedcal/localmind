# 15 — LocalMind Extension Domains

This section documents **every domain** LocalMind can extend into thanks to its universal Knowledge Graph engine. Each domain has a dedicated file (IT + EN) with an extended structure: what we solve, personas, input requirements, activity flow, graph model (nodes/edges/weights), data sources & connectors, features to build/develop/maintain (MVP → evolution), AI/GraphRAG use cases, KPIs, risks, maintenance, integration with existing modules.
